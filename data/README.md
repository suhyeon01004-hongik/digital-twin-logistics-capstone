# 데이터셋 관리 정책

이미지와 라벨은 Git 저장소에 직접 올리지 않습니다. 데이터셋은 OBB 모델의
재학습·평가·라벨 수정에만 필요하며, 이미 학습된 `best.pt`로 추론할 때는
필요하지 않습니다.

기본 로컬 데이터 루트는 `data/local`이고 `MILEMATE_DATA_ROOT`로 변경할 수
있습니다.

```text
data/local/
├─ raw/        원본 캡처와 변경 금지 자료
├─ interim/    검수·자동 라벨·포맷 변환 중간 결과
├─ processed/  학습에 사용하는 고정 버전
└─ exports/    외부 데이터·모델 저장소 업로드 결과
```

정리 원칙은 다음과 같습니다.

1. 원본은 읽기 전용으로 보관하고 파생본과 분리합니다.
2. 이미지 해시로 중복과 train/val/test 누수를 검사합니다.
3. 택배 주소, QR·바코드, 얼굴 등 개인정보를 공개 전에 제거합니다.
4. 출처, 라이선스, 변환 스크립트, seed와 디렉터리 체크섬을 기록합니다.
5. 대용량 데이터는 Drive, Hugging Face Dataset 등 접근 통제가 가능한 별도
   저장소에 버전으로 보관합니다.

발견된 원본과 규모는 `manifests/datasets.md`에 기록했습니다. 현재 목록은
인벤토리이며 공개 가능한 학습 정본을 확정한 것은 아닙니다.
