## 이번 점검에서 수정한 로직

- Ultralytics 추론에서 존재하지 않는 `quantize=16` 인자를 올바른 `half` 옵션으로
  교체했습니다.
- 플랫폼 Serial 연결이 끊긴 뒤 reader thread가 busy loop 또는 재연결 thread와
  중첩될 수 있던 수명주기를 종료·join 방식으로 수정했습니다.
- colcon install 경로에서 모델·MATLAB 루트를 잘못 계산할 수 있던 고정
  `parents[4]` 접근을 저장소 탐색 방식으로 교체했습니다.
- 일회성 MATLAB batch가 비정상 종료되어도 출력 marker만 있으면 성공으로
  처리할 수 있던 경로에 return code 검사를 추가했습니다.
- launch bool/int 인자를 명시적 ROS parameter type으로 전달했습니다.
- 모델 없이도 `start_perception:=false`로 제어부 dry-run이 가능하게 했습니다.
- 층별 벨트 펌웨어가 fault를 motion 시작 시 자동 해제하던 경로를 제거하고
  모든 fault 진입 시 모터를 정지하며 E-stop/fault latch 중 motion 명령을
  거부하도록 수정했습니다.
- 플랫폼 리프트의 수동 층 이동이 1~3층 소프트웨어 범위를 넘지 않도록 했습니다.
